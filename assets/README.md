# assets/

โฟลเดอร์สำหรับไฟล์รูปภาพที่ Dashboard ใช้อ้างอิงโดยตรง (ไม่ต้อง embed เป็น base64 ในไฟล์ HTML)

## วิธีเพิ่ม Poster การประกวด Digital & AI Talent 2569

1. เข้า https://github.com/jinnaphas/AIadoption
2. เข้าโฟลเดอร์นี้ (`assets/`)
3. กด **Add file** → **Upload files**
4. ลากไฟล์ภาพ Poster มาวาง แล้ว**ตั้งชื่อไฟล์เป็น `poster-2569.png` พอดี** (สำคัญ — ชื่อต้องตรงเป๊ะ ตัวพิมพ์เล็ก-ใหญ่ก็ต้องตรง)
5. กด **Commit changes** → เลือก commit ตรงเข้า `main` branch ได้เลย
6. รอ ~1 นาทีให้ GitHub Pages rebuild แล้วเปิดหน้าเว็บใหม่ — Poster จะขึ้นในหน้าแรกของ Tab "🏆 Digital & AI Talent 2569" ทันทีโดยไม่ต้องแก้โค้ดเพิ่ม

ถ้าไฟล์เป็นสกุลอื่น (.jpg, .webp) ให้เปลี่ยนนามสกุลตอนอัปโหลดให้เป็น `poster-2569.png` หรือแจ้งให้แก้โค้ดให้ตรงสกุลไฟล์แทน
